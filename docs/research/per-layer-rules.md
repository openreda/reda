# How other PCB tools express rules that vary by Layer

Research for REDA ticket #325. Sources were checked on 2026-11-18.

A Layer can select **where to measure**, **which objects to include**, or **which Layers a Via connects**. The difference is visible on a through Via. Its land can affect clearance on the top Layer even though the Via is assigned to multiple Layers. On an unconnected internal plane, the fabrication limit may instead measure from the drilled hole to the plane copper. Neither measurement determines the diameter of the drill. [The leading suite’s worked clearance example](https://www.altium.com/documentation/knowledge-base/altium-designer/layer-specific-design-rules-with-through-hole-pads-and-vias) · [The leading suite’s plane rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/plane) · [OSH Park four-Layer service](https://docs.oshpark.com/services/four-layer/)

## Which rule kinds vary, and how do they distinguish inner and outer Layers?

| Tool | Track width and copper clearance | Via size and annular ring |
| --- | --- | --- |
| the leading suite | One Width rule holds minimum, preferred and maximum Track widths for each signal Layer. A clearance can apply to all Layers, an inner or outer Layer group, or one named signal Layer. [Routing rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/routing) · [Constraint Manager](https://www.altium.com/documentation/altium-designer/sch-pcb/constraint-manager) | A routing rule can select a blind or buried Via by `StartLayer` and `StopLayer` and set its land and hole diameters. Minimum Annular Ring specifies one radial minimum for the selected Pads and Vias, measured from hole edge to land edge. The rule description gives no independent minimum for each land of a single through Via. [Routing rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/routing) · [Manufacturing rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/manufacturing) |
| a second commercial suite | A named physical constraint set holds Track-width limits. A separate spacing set holds clearances such as Track-to-Track and Track-to-Via. Each set provides a value per Layer for its constraints. The worksheets offer All Layers and By Layer views. A region can cover a named Layer, all outer Layers, inner signal Layers, inner plane Layers or the whole Stackup. [Physical and spacing model](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-01-31-45-92/constraint-in-16_5F00_0.pdf) · [Worksheet guide](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-00-96-42-32/cmug.pdf) | The physical set selects a list of permitted Vias. For example, power and signal Nets can use different Via lists. Via geometry comes from the selected padstack. Separate fabrication checks measure a pin or Via hole against its copper land. [Physical-set example](https://resources.academic.cadence.com/pcb-design-and-analysis-resources/2024-how-to-use-the-constraint-manager-in-orcad-x) · [Fabrication checks, §3](https://resources.pcb.cadence.com/home/col/rc/orcad-x-designtrue-dfm-rules-guide) |
| KiCad 10 | `track_width` and `clearance` are custom constraints. A Layer clause accepts a name such as `F.Cu`, `inner` for internal copper, or `outer` for front and back copper. A tuning profile assigned to a Net Class also supplies per-Layer Track width and differential-pair gap to the router. [PCB Editor manual, “Layer Clause” and “Tuning profiles”](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) | `annular_width` checks the ring on Pads and Vias. `via_diameter` checks a Via’s copper diameter, and `hole_size` checks the drill. The Via editor separately defines its geometry using one padstack for all Layers, front/inner/back settings, or individual Layer settings. [PCB Editor manual, constraint reference and Via properties](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) |
| Autodesk Fusion Electronics | The custom-rule editor publishes the filters available for each rule kind. Copper Width and Copper Clearance accept named signal Layers. An internal signal Layer can also carry a polygon Zone. [Custom rules](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-CUSTOM-RULES-CPT.htm) · [Multilayer routing](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-ROUTE-MULTILAYER-BOARD-CPT.htm) | Drill Size accepts a Via type or Net Class. Its documented filters omit signal Layer. Annular ring settings calculate a land from a fraction of drill diameter bounded by a minimum and maximum. Inner and outer lands can therefore have different diameters around the same drill. [Custom rules](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-CUSTOM-RULES-CPT.htm) · [Annular ring settings, Spanish edition](https://help.autodesk.com/cloudhelp/ESP/Fusion-ECAD/files/ECD-DESIGN-PREFERENCES-ANNULAR-RING.htm) |
| Horizon EDA | Horizon is included because its clearance editor puts two Net Class selectors, one Layer selector and an object-pair matrix in a single rule. Its published example shows separate Track, Pad, plane and Via entries with “Any layer” selected. [Rules editor, §2.7](https://horizon-eda.readthedocs.io/_/downloads/en/latest/pdf/) | A matching Via rule or a Via definition supplies the size. A separate Layer-pairs rule tells the router which Layer to switch to when placing a Via. [Board Editor, “Vias”](https://docs.horizon-eda.org/en/v2.5.0/imp-board.html) |

## How does a Layer scope combine with a Net Class, and which value wins?

| Tool | Scope and precedence |
| --- | --- |
| the leading suite | In the rule editor, `InNetClass('Power') And OnLayer('Top Layer')` selects objects meeting both conditions. Rules of the same kind have explicit priorities. The highest-priority match wins, with 1 highest. In Constraint Manager’s Physical and Electrical views, basic rules have automatic scope priority. An object overrides its class, and its class overrides All. [Rule editor](https://www.altium.com/documentation/altium-designer/pcb/defining-scoping-managing-design-rules) · [Membership checks](https://www.altium.com/documentation/altium-designer/pcb/query-functions/membership-checks) · [Constraint Manager](https://www.altium.com/documentation/altium-designer/sch-pcb/constraint-manager) |
| a second commercial suite | A Net Class can reference a physical set and a spacing set. The applicable Layer supplies the value within the set. A member inherits the value unless a more specific applicable object supplies one. An individual constraint override takes precedence over the value inherited from a set and may tighten or relax it. [Physical and spacing model](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-01-31-45-92/constraint-in-16_5F00_0.pdf) · [Inheritance and resolution](https://community.cadence.com/cadence_blogs_8/b/pcb/posts/leverage-object-hierarchy-for-effective-constraint-management) |
| KiCad 10 | A `.kicad_dru` rule can combine `(layer F.Cu)` with `(condition "A.hasNetclass('Power')")`. KiCad checks rules from the end of the file and takes the first match for the constraint. Net Class values apply unless a more specific rule overrides them. If a Net has several Net Classes, the highest-ranked class that supplies each property wins. No rule may lower a minimum in Board Setup’s Constraints. [PCB Editor manual, “Net classes” and “Custom design rules”](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) |
| Autodesk Fusion Electronics | A custom Track-width rule can select both a Net Class and signal Layers. The first matching rule in priority order wins, even when a later rule is more narrowly scoped. During interactive routing, Fusion uses the larger of the winning preferred value and the general value for Track width, copper clearance and Via drill size. [Custom rules](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-CUSTOM-RULES-CPT.htm) · [General rules](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-GENERAL-RULES-CPT.htm) |
| Horizon EDA | The first rule matching all criteria wins, reading the list from top to bottom. A class-and-Layer exception therefore goes above a broader rule that would also match. [Rule evaluation](https://docs.horizon-eda.org/en/latest/rules.html) · [Rules editor, §2.7](https://horizon-eda.readthedocs.io/_/downloads/en/latest/pdf/) |

**The leading suite uses one rule-management workflow per project.** Enabling Constraint Manager makes the standalone rule editor unavailable for that project. Within Constraint Manager, the PCB-side **All Rules** view shows the project’s basic and advanced rules together. Each clearance-matrix class pair appears as one basic rule, including its Layer-specific values. Matching advanced rules outrank basic rules. Advanced rules have editable priorities with 1 highest, while basic-rule priorities are automatic. There is no further priority comparison against a second set maintained in the standalone editor. [The leading suite’s Constraint Manager, “Working with All Rules on the PCB Side”](https://www.altium.com/documentation/altium-designer/sch-pcb/constraint-manager)

**A second commercial suite resolves region exceptions by location.** A region is a drawn boundary on the selected Layers. A different width or clearance can take effect where a Net enters it. A Region Class sets an exception for one Net Class inside that boundary. For the scopes relevant here, the documented spacing hierarchy runs from design default to Net Class, Net, Net Class pair, region, Region Class, then Region Class pair, in increasing precedence. Physical constraints follow the same relevant levels through Region Class, omitting both class-pair levels. The full hierarchy also includes grouping and connection objects such as buses, differential pairs and pin pairs. Only applicable objects participate. [Worksheet guide, “Constraint Object Hierarchy”](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-00-96-42-32/cmug.pdf) · [Region examples](https://community.cadence.com/cadence_blogs_8/b/pcb/posts/physical-spacing-constraints) · [Inheritance and resolution](https://community.cadence.com/cadence_blogs_8/b/pcb/posts/leverage-object-hierarchy-for-effective-constraint-management)

## How does a Layer qualify clearance between two Net Classes?

| Tool | How to express a class pair on a Layer |
| --- | --- |
| the leading suite | Select the two Net Classes by row and column in the clearance matrix. In that cell, `5/6` assigns 5 to inner Layers and 6 to outer Layers in the current units. The detail grid refines individual object pairs, such as Track-to-Via. For the same pair, a named Layer wins over its inner or outer group, which wins over All Layers. The documentation explicitly assigns higher priority to more specific Layers and Layer groups. [Constraint Manager, “Working with the Clearance Matrix”](https://www.altium.com/documentation/altium-designer/sch-pcb/constraint-manager) |
| a second commercial suite | Create a **Net Class-Class** entry in the Spacing worksheet. It can represent two different Net Classes or spacing among members of one Net Class. Assign a spacing set to the entry and set the object-pair clearance for the relevant Layer. A **Region Class-Class** entry specializes that pair within a region. Same-Net spacing has a separate worksheet and does not use these class-pair objects. [Worksheet guide, “Net Class-Class” and “Region Class-Class”](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-00-96-42-32/cmug.pdf) · [Per-Layer spacing sets](https://community.cadence.com/cfs-file/__key/telligent-evolution-components-attachments/00-27-01-00-01-31-45-92/constraint-in-16_5F00_0.pdf) |
| KiCad 10 | A `clearance` rule can combine `(layer inner)` with `(condition "A.hasNetclass('Power') && B.hasNetclass('Sense')")`. One rule covers the pair. The manual’s **Condition Clauses** section says that the checker “will test both possible orderings.” Its Layer Clause section gives a separate worked example using `(layer outer)`. [PCB Editor manual, passage on object ordering](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html#:~:text=The%20order%20of%20the%20two%20objects) |
| Autodesk Fusion Electronics | For different Nets, Object 1 and Object 2 each accept a Net Class and signal Layer filter. For same-Net clearance, Net Class goes in the shared scope, while the objects retain their Layer filters. [Custom rules, scope table](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-CUSTOM-RULES-CPT.htm) |
| Horizon EDA | Select the first and second Net Classes, choose the Layer for the rule, then set clearance for each kind of object pair in the matrix. The Layer qualifies the pair as a whole. List position determines which matching rule supplies that matrix. [Rules editor, §2.7](https://horizon-eda.readthedocs.io/_/downloads/en/latest/pdf/) · [Rule evaluation](https://docs.horizon-eda.org/en/latest/rules.html) |

For the leading suite’s query-based rules, `OnLayer('Top Layer')` tests the object’s assigned Layer. A through-hole Pad or Via has a multilayer assignment. `ExistsOnLayer('Top Layer')` includes it when it has geometry there. These are **membership checks**. The separate **Layer checks** reference documents `OnMid` for internal signal Layers, `OnOutside` for outer signal Layers and `OnPlane` for internal plane Layers. A power-plane clearance rule measures from the **hole edge** to the plane copper. [Membership checks](https://www.altium.com/documentation/altium-designer/pcb/query-functions/membership-checks) · [Worked through-hole example](https://www.altium.com/documentation/knowledge-base/altium-designer/layer-specific-design-rules-with-through-hole-pads-and-vias) · [Layer checks](https://www.altium.com/documentation/altium-designer/pcb/query-functions/layer-checks) · [Plane rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/plane)

## Which silkscreen rules can differ between top and bottom?

| Tool | Width and text height | Clearance and side selection |
| --- | --- | --- |
| the leading suite | Text height and stroke width are text properties. The manufacturing-rule catalogue documents no dedicated minimum for either dimension or for a drawn silkscreen line’s width. [Text properties](https://www.altium.com/documentation/altium-designer/pcb/text-objects) · [Manufacturing rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/manufacturing) | `OnTopSilkscreen`, `OnBottomSilkscreen` and `OnSilkscreen` select the side or both sides. Silk-to-silk checks text against other legend objects. Silk-to-mask can measure to the full mask opening or only to exposed Pad copper. Top and bottom mask expansion can themselves differ, changing the opening being checked. [Layer checks](https://www.altium.com/documentation/altium-designer/pcb/query-functions/layer-checks) · [Manufacturing rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/manufacturing) · [Mask rules](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/mask) |
| a second commercial suite | The silkscreen fabrication set has a minimum width for lines, arcs and shapes. Its published list includes text overlap and text spacing checks. It gives no dedicated minimum text-height rule. [Fabrication checks, §6](https://resources.pcb.cadence.com/home/col/rc/orcad-x-designtrue-dfm-rules-guide) | The set checks silk against pin Pads, Via Pads and non-plated holes. It also checks text against lines, shapes and text on the same silk Layer. A community answer describes exposing top and bottom silkscreen separately in the Stackup for assignment (not verified: secondary source). [Fabrication checks, §6](https://resources.pcb.cadence.com/home/col/rc/orcad-x-designtrue-dfm-rules-guide) · [Community answer on side selection](https://community.cadence.com/cadence_technology_forums/pcb-design/f/allegro-x-pcb-editor/74719/orcad-x-25-1-pro-cant-set-dfa-constraints) |
| KiCad 10 | A named front or back silkscreen Layer can qualify `text_height` and `text_thickness`. For a drawn graphic line, a custom `assertion` can test the shape’s `Line_Width`. [PCB Editor manual, constraint and property references](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) | `silk_clearance` controls spacing. The ordinary silk-to-silk readability check skips collisions involving only graphic shapes, but reports a line intersecting text. Separate checks identify silk crossing a mask opening or the board edge. [PCB Editor manual, “Readability DRC checks”](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) |
| Autodesk Fusion Electronics | The published rule categories give no dedicated silk line-width, text-height or text-thickness check. [Rule categories](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-DESIGN-RULES-CATEGORIES-CPT.htm) | Mask-to-silk clearance accepts a top or bottom mask Layer for one object and the corresponding silk, name or value Layers for the other. [Custom rules, scope table](https://help.autodesk.com/cloudhelp/ENU/Fusion-ECAD/files/ECD-CUSTOM-RULES-CPT.htm) |
| Horizon EDA | The published rules overview does not establish a minimum legend line width or text height. [Rules editor, §2.7](https://horizon-eda.readthedocs.io/_/downloads/en/latest/pdf/) | The editor shows a silkscreen-to-exposed-copper check. The example does not show independent top and bottom limits for it. [Rules editor, §2.7](https://horizon-eda.readthedocs.io/_/downloads/en/latest/pdf/) |

## What hobbyists at 4 to 6 Layers actually use

Raspberry Pi publishes a four-Layer KiCad carrier for its Pico VGA, SD-card and audio example. Section 3, pp. 15–16, identifies the carrier and explains the choice of internal power and ground Layers. Page 22 gives a concrete use for the Stackup: with 0.36 mm between the outer signal Layer and the adjacent reference Layer, the designers used 0.3 mm Tracks for approximately 75 Ω on the VGA colour outputs. This is a documented width choice for particular signals on one board. (Not verified on review: the PDF's text could not be extracted to confirm the Layer count, page numbers or the 0.3 mm and 75 Ω figures.) [Raspberry Pi hardware design guide, §3](https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf)

OSH Park’s KiCad instructions give another example of how a prototype board is set up. The four- and six-Layer services share board-wide minimum Track width, clearance and annular ring settings. Their minimum Via diameters differ by service. OSH Park leaves signal-specific Net Classes to the designer and gives a silkscreen text-thickness value while leaving text height to user preference. Its Stackup dimensions matter when KiCad calculates controlled impedance. [OSH Park KiCad design-rule setup](https://docs.oshpark.com/design-tools/kicad/kicad-design-rules/)

| Prototype service | Inner and outer Layer distinctions in the published limits |
| --- | --- |
| OSH Park, four and six Layers | Both services specify 5 mil Track width and spacing, with 1 oz outer and ½ oz inner copper. Both require 10 mil from a plated drill to unconnected internal copper. The four-Layer page warns that some tools suppress the annular ring when a Via has no connection on an internal Layer. OSH Park recommends configuring the tool to include the rings regardless of connection. [Four-Layer service](https://docs.oshpark.com/services/four-layer/) · [Six-Layer service](https://docs.oshpark.com/services/six-layer/) |
| JLCPCB, multilayer rigid boards | The capabilities page groups minimum Track width and spacing by copper weight and board Layer count. It gives no separate inner and outer Track-width or spacing figures. It does specify 0.5 oz default inner copper and two inner-Layer hole-edge clearances: 0.20 mm from a Via hole to copper and 0.30 mm from a plated through-hole Pad hole to copper. [Rigid-board capabilities](https://jlcpcb.com/capabilities/pcb-capabilities/) |
| PCBWay | The detailed capability table distinguishes inner and outer image-transfer limits. For 18 µm copper in its normal process, before compensation, it lists 4 mil minimum Track width on both, with 4 mil spacing inside and 5 mil outside. Those figures belong to that copper thickness and process category. [PCB capabilities, image-transfer items 14–15](https://www.pcbway.com/capabilities.html) |
| AISLER | The four-Layer 70 µm ENIG service has 70 µm outer and 35 µm inner copper. For that build, both minimum Track width and minimum copper-to-copper spacing are 175 µm outside and 125 µm inside. AISLER publishes separate rules for its other builds. [PCB portfolio](https://community.aisler.net/t/pcb-portfolio/101) · [Four-Layer 70 µm ENIG design rules](https://community.aisler.net/t/4-layer-70-m-enig-design-rules/5772) |

## Review notes

These claims were checked against their sources on 2026-11-18 and matched: the leading suite's Layer checks (`OnMid`, `OnOutside`, `OnPlane` and the silkscreen predicates), its clearance matrix (the inner/outer slash notation and the rule that more specific Layers win), KiCad's reverse-order first-match evaluation, KiCad testing both object orderings, Horizon EDA's top-to-bottom first match, OSH Park's four-Layer limits, JLCPCB's inner-Layer hole-to-copper clearances, and AISLER's 175 µm outer and 125 µm inner Track and spacing minimums.

These could not be confirmed on review and should be treated as not verified:

- The second commercial suite's constraint hierarchy and override behaviour, sourced from its vendor blog. That page returned HTTP 403 to an automated fetch.
- The second commercial suite's silkscreen and fabrication checks. The guide's landing page only summarises its contents, and the linked PDF is a scanned image without extractable text.
- The Raspberry Pi four-Layer carrier details (see above).
- AISLER's copper thicknesses (70 µm outer, 35 µm inner), which do not appear on the linked design-rules page and may come from the portfolio page.
