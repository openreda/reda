# Form-factor mechanical specs for Board Templates

Research for the issue "Research: official mechanical specs for common board form factors" (openreda/reda#394), collected 2026-11-20 from primary sources only.

- [maker.md](maker.md): Raspberry Pi HAT+ / HAT / uHAT, Pico and Pico 2, Seeed XIAO
- [hobby.md](hobby.md): Arduino Uno R3/R4, Mega 2560, Nano; Adafruit Feather; SparkFun MicroMod and Qwiic; ESP32-DevKitC V4, ESP32-S3-DevKitC-1
- [industry.md](industry.md): PCIe CEM add-in card, M.2, mikroBUS add-on boards, Eurocard, PC/104 and PC/104-Plus

Each value is marked Verified, Partial or Unverified, with its source. Licensing: ship only the bare numbers, redrawn as our own geometry, and never bundle vendor files, figures or text.
