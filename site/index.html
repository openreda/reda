Schematic to fab, in one free app.

REDA is an open-source electronics design tool. In one window you draw a circuit, lay out the PCB that makes it real, and write the files a fab needs to make and assemble your board.

It is MIT licensed, written in Rust, runs on Windows, macOS and Linux, and never phones home.

Download the latest build Source on GitHub

REDA is at an early stage. Expect missing features, rough edges and file-format changes between releases. The builds are not signed yet; the README explains how to open them.

What v0.1 does

Version 0.1 takes you from an empty Project to a zip you can upload to a board house: a 2-layer board, drawn and routed by hand, checked and plotted.

Schematic

  • Several flat sheets per Project, joined by net labels and power ports.
  • Place Parts from a Library, wire them up, and annotate designators.
  • Highlight a net and see it on every sheet.
  • Export the schematic to PDF.

PCB layout

  • Sync the schematic to the board; a change list shows what will happen first.
  • Place footprints on the top or bottom side and route tracks by hand, with vias.
  • Copper Zones (pours) with thermal reliefs, refilled before checks and outputs.
  • Clicking a part in one editor selects it in the other.

Checks

  • ERC finds unconnected pins, clashing outputs and dangling wires.
  • DRC checks clearances, track widths, drills and the board edge against your rules.
  • Every problem is listed in the Messages panel; click it to go there, or waive it.

Outputs for the fab

  • Gerber X2, Excellon drill files, a CSV BOM and a pick-and-place (CPL) file.
  • Fab Presets for JLCPCB, PCBWay and a generic house set the rules and the BOM columns.
  • One click writes everything into a single zip.

Parts and Libraries

  • A starter Library of passives, LEDs, diodes, transistors, an op-amp, a 555, an LDO and connectors.
  • Editors for Symbols, Footprints and Parts.
  • Footprint generators for chips, SOT, SOIC, QFN, QFP, DIP and headers (IPC-7351).
  • Import a part from a KiCad symbol and footprint, as vendor sites provide them.

Works with scripts and AI agents

  • Every action is a Command, the same in the app, the reda command line and MCP.
  • An agent can draw, route, check and plot a board, and you watch it happen in the app.
  • Undo works the same whoever made the change.

Get REDA

Download

Every change to REDA is released on GitHub. The latest release always holds the newest build; all releases are kept.

  • macOS (Apple Silicon): .dmg
  • Windows (x86_64): an installer that needs no administrator rights
  • Linux (x86_64, aarch64): .deb or .AppImage
  • Any of these: a plain .tar.gz or .zip

SHA256SUMS beside the files lets you check your download.

Command line and MCP

Every package ships the reda command-line tool beside the app. reda commands lists what it can do, reda run runs a Command on a Project, and reda mcp serves REDA to MCP clients such as AI coding agents.

When the app has the same Project open, the command line drives the running app instead, so you see each change.

Private by design

REDA makes no network calls on its own. There is no telemetry, no account and no automatic update check. Help → Check for Updates asks GitHub only when you click it.

This website has no analytics, no trackers and no third-party fonts or scripts either.
