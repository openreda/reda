# The hand-kept part of THIRD_PARTY_NOTICES: third-party data REDA bundles that is not a
# Rust crate's code (docs/spec/v0.1/app.md#icons, ADR-0002). reda-ui's build script turns
# this into the "Bundled data" part of the notices built into the binary and shown under
# Help > About > Licences; cargo-about adds the crate licences at release time.
#
# Format: an entry starts with `== Title ==`. `Key: value` lines are copied into the notices
# as they are, except `Text:`, which names a file (from the repo root) whose contents are
# copied in. Every folder holding vendored data must have a `Directory:` line;
# crates/reda-ui/tests/notices.rs finds such folders by their licence and font files and
# fails when one is missing here. Lines starting with `#` are comments.

== Placeholder icons (Lucide and Tabler) ==
