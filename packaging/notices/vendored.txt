# The hand-kept part of THIRD_PARTY_NOTICES: third-party data REDA bundles that is not a
# Rust crate's code (docs/spec/v0.1/app.md#icons, ADR-0002). reda-ui's build script turns
# this into the "Bundled data" part of the notices built into the binary and shown under
# Help > About > Licences; cargo-about adds the crate licences at release time.
#
# Format: an entry starts with `== Title ==`. `Key: value` lines are copied into the notices
# as they are, except `Text:`, which names a file (from the repo root) whose contents are
# copied in. Every folder holding vendored data must have a `Directory:` line;
# crates/reda-ui/tests/notices.rs finds such folders by their licence and font files and
# fails when one is missing here. Lines starting with `#` are comments.

== Inter ==
Directory: crates/reda-ui/fonts/inter
Used for: the window's UI text, in regular, medium and semibold. Inter-Tabular.ttf is a modified version made by REDA: Inter Regular with the glyphs of its tabular-figures feature (tnum) as the default ones in its character map, for numbers that must line up.
Licence: SIL Open Font License 1.1. Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter)
Text: crates/reda-ui/fonts/inter/OFL.txt

== JetBrains Mono ==
Directory: crates/reda-ui/fonts/jetbrains-mono
Used for: the window's monospace text (the Journal, file names, command and key text). The file is JetBrains Mono NL Regular, the build without ligatures, unmodified.
Licence: SIL Open Font License 1.1. Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono)
